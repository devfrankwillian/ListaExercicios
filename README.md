# ☕ Lista de Exercícios - Programação Orientada a Objetos (POO)

Repositório dedicado à resolução da lista de exercícios práticos e teóricos de Programação Orientada a Objetos em Java, focando na preparação para a prova bimestral.

## 🎯 Conceitos Abordados
Ao longo desta lista, os seguintes pilares e conceitos do Java foram aplicados e explicados:
* Criação de Classes e Instanciação de Objetos
* Encapsulamento (Modificadores `private`, Getters e Setters)
* Construtores e Sobrecarga de Métodos
* Gerenciamento de Memória (Passagem por Referência vs Valor, Stack e Heap)
* Atributos e Métodos de Classe (`static`)
* Constantes (`final`)
* Estruturas de Dados Dinâmicas (`ArrayList` e laço `for-each`)
* Entrada de Dados via Console (`Scanner`)

## 📂 Estrutura do Repositório

A lista é dividida em duas grandes partes:

### Parte 1: Fundamentos (Exercícios 1 ao 15) ✔️
Um projeto incremental focado na evolução de uma classe `Carro` e testes teóricos de escopo e referência na memória. Finalizado com a criação de um mini-sistema interativo no console para gerenciar uma frota de veículos.
* `Carro.java`: Classe principal com as regras de negócio e validações.
* `Cliente.java`: Classe para testes de sobrecarga de construtores.
* `Main.java`: Ponto de entrada do sistema e execução das comprovações teóricas.

### Parte 2: Histórinhas (Exercícios 16 ao 20) 🚧
Aplicações de cenários reais usando pacotes separados:
* `lanchonete/`: Sistema de pedidos do Seu Jorge (Ex 16).
* `estacionamento/`: Controle de lotação do Carlão (Ex 17).
* `academia/`: Gestão de alunos da Fernanda (Ex 18).
* `locadora/`: Acervo de filmes do Marcos (Ex 19).
* `delivery/`: Venda de marmitas da Camila (Ex 20).
